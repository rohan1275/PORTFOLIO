## 📌 Overview

This project is my **personal portfolio website**, built to present my profile, technical skills, featured projects, certifications, and contact information in a clear and visually engaging way.

The website focuses on creating a strong first impression through:

- a **clean and modern design**
- **responsive layout** across screen sizes
- **smooth user navigation**
- **interactive frontend elements**
- a structured showcase of my work and background

It serves as both a professional online presence and a practical frontend project demonstrating core web development skills.

## ✨ Features

- **Responsive portfolio layout**  
  Designed to work smoothly across desktop, tablet, and mobile devices.

- **Modern landing section**  
  A strong hero section with clear introduction, call-to-action buttons, and quick access to resume/contact links.

- **About section**  
  Highlights academic background, interests, and personal introduction.

- **Skills showcase**  
  Displays technical skills across programming, frontend, cloud, DevOps, databases, and tools.

  Presents selected projects with short descriptions and technology tags.

  Adds academic and technical certifications to strengthen professional credibility.

  Provides direct ways to connect through email and LinkedIn.

  Includes polished navigation and interactive frontend behavior for a better user experience.

  Adds a modern visual experience and improved usability.

## ⚙️ Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/rohan1275/PORTFOLIO.git
cd PORTFOLIO
```

### 2. Open the project
You can open `index.html` directly in your browser.

### 3. Run locally with Live Server
If you use VS Code, install the **Live Server** extension and run the project locally for a better development experience.

### 4. Customize content
Update the following based on your latest profile:

- personal introduction
- skills
- featured projects
- certifications
- contact links
- resume link
